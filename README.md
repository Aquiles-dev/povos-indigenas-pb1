# Povos Indígenas da Paraíba

Projeto desenvolvido em HTML, CSS e JavaScript com o objetivo de apresentar informações sobre alguns povos indígenas da Paraíba.

A aplicação foi criada como parte de uma apresentação para a **Semana Acadêmica Unificada (SAU) do IFPB**, utilizando conceitos de desenvolvimento web para construção de uma página informativa e interativa.

## Acesse o projeto

O projeto está disponível através do GitHub Pages:

[Visitar site](https://aquiles-dev.github.io/povos-indigenas-paraiba/)

## Sobre o projeto

A página apresenta informações históricas e culturais sobre povos indígenas presentes na Paraíba, organizando o conteúdo de forma visual e acessível.

O projeto foi desenvolvido como uma aplicação web estática, utilizando tecnologias fundamentais do desenvolvimento frontend.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto
